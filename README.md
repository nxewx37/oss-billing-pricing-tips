# OSS（对象存储服务）的计费方式有哪些：按量付费和资源包怎么选，存储、流量、请求各项单价与避坑点一次讲清

OSS 的计费方式只有两种：**按量付费**和**包年包月（资源包）**。开通 OSS 之后默认就是按量付费，系统每小时统计你前一小时的实际用量，从账户余额里扣钱，不需要提前买任何东西。资源包则是先把存储量或流量买成固定规格，用量在包内就不再计费，超出的部分回到按量结算。

## 两种计费方式分别怎么扣钱

按量付费是“先使用、后付费”，包年包月是“先购买、后使用”，两者可以同时生效：资源包管得住的部分走包内额度，管不住的每小时按量结算。

### 按量付费（后付费）

开通即默认生效，支持标准、低频、归档、冷归档、深度冷归档全部存储类型。系统每小时统计前一小时的实际用量并从余额扣款，账户里有余额就能直接用。

适合用量波动大的业务，比如备份数量不固定、测试环境。代价是账单随用量走，可以在 OSS 控制台的监控服务里查看实际使用量，用量异常能第一时间发现。

### 包年包月（资源包）

资源包主要覆盖存储和流量两类计费项，分存储包、下行流量包（抵扣外网流出）、回源流量包（抵扣 CDN 回源）三种，需要分别购买。规则有五条：

1. 包内规格内的用量不收费，超出部分每小时按量结算
2. 流量包当月额度用不完不结转到下月，超出部分按量计费
3. 资源包与地域绑定：Bucket 建在哪个地域，包就得买在哪个地域，跨地域不共享
4. 生效期可选支付后立即生效或指定日期，生效前的用量照常按量计费
5. 资源包到期不影响已有数据，账户余额充足时自动转回按量；没用过的资源包支持退款，提交工单处理

> 存储包只抵扣对应存储类型的存储费用。只买了标准型存储包，低频、归档产生的存储量照样按量扣费。

## 按量付费到底按什么收费：四个计量项逐个拆

按量付费的账单由四类计量项构成：存储、流量、请求、数据处理，各自按实际用量乘单价结算。

### 存储费用：按 GB/月计价，五种存储类型

OSS 按数据冷热分五种存储类型，单价从热到冷递减。中国内地各地域按量单价统一（中国香港、海外地域和金融云价格另算）：

| 存储类型 | 本地冗余（元/GB/月） | 同城冗余（元/GB/月） |
| --- | --- | --- |
| 标准 | 0.12 | 0.15 |
| 低频访问 | 0.08 | 0.10 |
| 归档 | 0.033 | 0.033 |
| 冷归档 | 0.015 | / |
| 深度冷归档 | 0.0075 | / |

本地冗余和同城冗余的差别在数据冗余机制，同城冗余贵一些。选型逻辑很简单：频繁访问的网站图片、音视频用标准；一年碰不了几次的备份数据用低频或归档；基本只存不读的合规档案用冷归档、深度冷归档。

存储量的计量不止“实际存的容量”一项，还包括数据取回量，以及未满最短存储天数就被删除的容量，后面避坑部分细说。

### 流量费用：只收下行，上传免费

| 流量类型 | 单价 |
| --- | --- |
| 内/外网流入（上传到 OSS） | 免费 |
| 内网流出（同地域 ECS 内网下载） | 免费 |
| 外网流出 | 闲时（00:00–08:00）0.25 元/GB，忙时（08:00–24:00）0.50 元/GB |
| CDN 回源流出 | 0.15 元/GB |
| 跨区域复制（复制到中国内地） | 0.50 元/GB |
| 跨区域复制 RTC | 0.10 元/GB |

OSS 只对下行流量收钱。真正会出账单的是三种场景：外网把数据下载到本地、CDN 回源拉数据、跨区域复制同步数据。访问量大的网站可以配 CDN，让用户从边缘节点取文件，OSS 侧只产生 0.15 元/GB 的回源流量，比外网流出的忙时价便宜一大截。

### 请求费用：免费额度只给标准存储

每次 API 调用都计请求次数，在控制台里的操作也算，因为控制台本质上就是调 API。按 PUT / GET 分类：

- 标准存储：PUT 每月每地域 0–500 万次免费，超出 0.01 元/万次；GET 0–2000 万次免费，超出 0.01 元/万次
- 低频、归档、冷归档：PUT 和 GET 都是 0.1 元/万次，没有免费额度
- 深度冷归档：PUT 3.5 元/万次，GET 0.1 元/万次
- 取回请求（触发解冻时）：冷归档 30 / 3 / 0.3 元/万次（高优先级 / 标准 / 批量），深度冷归档 7 / 1.67 元/万次

同为 PUT，深度冷归档的单价是标准存储的 350 倍。海量小文件放错存储类型，请求费可能比存储费还高。

### 数据处理与数据取回

- 图片处理：每月 0–10 TB 免费，超出 0.025 元/GB；高级压缩低规格 0.025 元/千次、中规格 0.1 元/千次
- 视频截帧：0.1 元/千张
- 数据取回（读冷数据时）：标准免费；低频 0.0325 元/GB；归档 0.06 元/GB；冷归档 0.2 / 0.06 / 0.03 元/GB（高优先级 / 标准 / 批量）；深度冷归档 0.13 / 0.018 元/GB（高优先级 / 标准）
- 归档直读：0.2 元/GB

冷归档、深度冷归档的数据要先解冻才能读，解冻产生的临时副本按 0.12 元/GB/月 单独收临时存储容量费。

还有一些低频触发的增值项：对象标签 0.0567 元/万个/月、传输加速（境外访问内地）1.25 元/GB、OSS 加速器 0.70 元/GB/月、敏感数据保护 0.20 元/GB。不开通、不使用就不计费，普通场景基本碰不到。

## 哪些项目是免费的

全程免费的有五项，其中前两项最容易被忽略：

1. 上传流量：内网、外网流入全部免费
2. 内网流出：同地域 ECS 通过内网 Endpoint 读数据免费
3. 标准存储请求：每月每地域 500 万次 PUT + 2000 万次 GET
4. 图片处理：每月 10 TB 以内免费
5. 标准存储的数据取回：免费

把 ECS 和 Bucket 建在同一地域，应用读写走内网，这部分流量费就是零。用量小的项目，光靠这几条免费额度就能把账单压得很低。

## 四个容易多花钱的地方

这几条都写在计费规则里，但经常被汇总文章一带而过。

### 坑一：低频和归档有最短存储时间

低频访问型最短存 30 天，归档型最短 60 天，提前删除或覆盖，剩余天数的存储费照收。官方文档给过算法：未满天数的费用 = 每个删除文件的大小 × 距最短存储时间剩余的小时数 × 对应类型的小时单价。举例来说，100 GB 的低频文件存到第 7 天删除，要按剩余约 23 天补收存储费。

低频和归档的对象最小计量单位是 128 KB，不足 128 KB 的文件按 128 KB 算。几百万条几 KB 的小记录放进低频桶，存储账单会被明显放大。

### 坑二：冷数据的请求单价翻着倍地涨

低频、归档、冷归档的 PUT/GET 请求是 0.1 元/万次，标准存储是 0.01 元/万次，前者是后者的 10 倍且没有免费额度；深度冷归档的 PUT 更是 3.5 元/万次。再把数据取回费叠上去（低频 0.0325 元/GB、归档 0.06 元/GB），访问频繁的数据放冷桶，省下的存储费远不够填请求和取回的窟窿。选存储类型前，先看数据的真实访问频率。

### 坑三：外网流量闲忙时价差一倍

外网流出凌晨 0:00–8:00 是 0.25 元/GB，8:00–24:00 是 0.50 元/GB。批量拉数据、迁移这类时间可控的操作放到闲时跑，流量费直接减半。

### 坑四：资源包买错地域或类型等于白买

资源包与地域、存储类型双重绑定。Bucket 在北京、包买到杭州，北京的用量照样按量扣；数据是归档类型、买的是标准存储包，同样抵扣不了。下单前先确认 Bucket 所在地域和实际使用的存储类型。开了跨区域复制还要注意：除了 0.50 元/GB 起的复制流量费，每同步一个对象都会累计一次请求计费。

## 按量付费还是资源包，按场景选

- 存储量长期固定（网站素材、归档库）：对应类型的存储包年付，1 TB 一年比按量省约三成
- 用量波动大（备份轮换、测试数据）：不买包，纯按量付费，不为用不满的规格花钱
- 下载流量大且稳定：先配 CDN 走 0.15 元/GB 的回源流量，外网流出量稳定就再配下行流量包
- 冷数据、合规归档：归档或冷归档按量起步即可，需要频繁取回的数据别放太冷

## 几个常见问题

**开通 OSS 后不买资源包，会自动扣费吗？**
会。默认就是按量付费，每小时按实际用量从账户余额扣款，账户里保持有余额即可。

**往 OSS 上传数据收流量费吗？**
不收。内网、外网上传全部免费，收费的是下载方向的外网流出。

**在 OSS 控制台操作也会产生费用吗？**
会。控制台操作本质上也是 API 调用，计入请求次数。标准存储每月 500 万次 PUT、2000 万次 GET 的免费额度内没有实际影响，超出后 0.01 元/万次。

**资源包没用完能退吗？**
没有使用过的资源包支持退款，提交工单由客服处理。

**归档的数据要读出来，会花哪些钱？**
主要是数据取回费 0.06 元/GB（归档型）；也可以开通归档直读，按 0.2 元/GB 计取回容量。读取走外网的话，再叠加外网流出流量费。

## 下单前的最后确认

只需要确认两件事：Bucket 建在哪个地域，存的到底是什么冷热类型的数据。确认完按这个顺序选：存储稳定就买对应类型的存储包，年付；流量稳定就配流量包；都不稳定就保持按量付费，配合控制台的用量监控兜底。

冷归档、深度冷归档这类超低价档位，先想清楚取回频率再选，解冻流程和取回费用都比普通存储复杂。拿不准的时候，低频是比归档更稳妥的折中。
